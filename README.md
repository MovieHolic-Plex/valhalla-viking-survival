# 발할라 (Valhalla) — 바이킹 서바이벌

> 절차적으로 생성되는 북유럽 세계에서 **채집하고, 짓고, 만들고, 신들에게 버림받은 보스를 사냥하는** 3D 오픈월드 서바이벌 게임.

## 이게 뭔가요

[Valheim](https://www.valheimgame.com/) 을 연구한 뒤, 그 **핵심 게임 루프와 진행 구조를 Godot 으로 처음부터 다시 구현**한 팬 오마주입니다.

- Iron Gate AB 및 Valheim 과 **무관한 비공식 팬 프로젝트**이며, 원작의 에셋·코드·데이터를 일절 사용하지 않았습니다.
- 등장 이름은 북유럽 신화에서 따왔거나 자체 창작한 것입니다.
- 상업적 목적이 없으며, 학습·연구용으로 공개합니다.

**핵심 기술적 특징: 이 저장소에는 3D 모델 파일도, 오디오 파일도 없습니다.**
나무·바위·몬스터·보스·건축물·아이템 아이콘·지형·효과음까지 전부 실행 시점에 GDScript 로 생성합니다.
지면·소재 텍스처 11종(잔디·흙·바위·눈·모래·나무껍질·판자·석조·직물·금속·잿불)만
[ambientCG](https://ambientcg.com/) 의 CC0 실측 소스를 128px 근백색 그레이스케일로 가공해
`assets/textures/` 에 넣고 씁니다. 지형 셰이더는 텍스처 명암 구배로 노멀을 꺾는
범프 릴리프까지 적용해 빛이 표면 요철에 반응합니다. 파일이 없는 종류(털·초가·잎)는 기존 절차적 생성으로 대체합니다.
(그 외 포함된 바이너리는 한글 폰트 3개뿐 — 나눔글꼴, SIL OFL)

## 구현된 것

### 세계
- **시드 기반 절차적 월드** — 반지름 2.4 km 의 섬. 같은 시드는 항상 같은 지형·자원 배치를 만듭니다.
- **7개 바이옴**: 초원 → 검은 숲 → 늪지 → 설산 → 평원 → 안개의 땅 → 잿불의 땅.
  중심에서 멀어질수록 위험해지는 링 구조 + 노이즈 교란.
- **청크 스트리밍** — 거리별 3단계 LOD, 스커트로 균열 은폐, 하이트맵 충돌.
- 지형 실루엣은 대륙 노이즈 위에 **바위 노두(능선 노이즈) · 단구(계단 지형) ·
  골짜기 침식** 세 겹을 얹어 만듭니다. 노두는 고지대일수록 날카로워져
  설산이 바위 능선이 되고, 저지대에서는 완만한 둔덕으로 남습니다.
- **지면 잡동사니** — 쓰러진 통나무 · 돌무더기 · 고사리 · 드러난 뿌리를
  바이옴별 밀도로 깔아 바닥이 비어 보이지 않게 합니다.
- **낮/밤 30분 주기**, 7종 날씨(맑음·흐림·비·폭풍우·눈보라·짙은 안개·잿비), 바이옴별 안개 색/밀도.
- 파도치는 바다 + 수중 시야/호흡, 수영 시 기력 소모.

### 생존
- **체력 · 기력 · 음식 3슬롯** — 발헤임과 동일하게 음식이 최대 체력/기력과 재생을 결정합니다.
- 상태이상: 젖음 · 추움 · 혹한 · 중독 · 화상 · 휴식(안락도 기반).
- **14종 숙련도** (달리기/도약/수영/은신/방어/도끼/둔기/검/창/단검/활/맨손/곡괭이/벌목) — 쓸수록 오르고, 죽으면 5% 감소.
- 사망 시 **무덤**에 소지품 전부 보관, 침대에서 부활.

### 전투
- 근접(베기·타격·관통·화염·냉기·독·번개·영혼 8종 데미지 타입), 활 조준/차징, 방어·**패링**, 구르기 무적 프레임.
- 방어도 감쇠 공식, 넉백, 경직(스태거), 도구 등급 판정("도구가 약하다").
- **30종 몬스터** — 바이옴/시간대별 스폰, 무리 짓기, 은신 감지, 원거리 탄도 예측, 습격 이벤트.

### 보스 7종
| 보스 | 바이옴 | 공물 | 포세이큰 파워 |
|---|---|---|---|
| 에이크시르 | 초원 | 사슴 트로피 x2 | 달리기/도약 기력 감소 |
| 고목의 왕 | 검은 숲 | 고대의 씨앗 x3 | 받는 피해 감소 |
| 본매스 | 늪지 | 말라붙은 뼈 x10 | 물리 저항 |
| 모데르 | 설산 | 용의 알 x3 | 순풍/낙하 피해 감소 |
| 야글루스 | 평원 | 풀링 트로피 x5 | 이동 속도 증가 |
| 안개의 여왕 | 안개의 땅 | 갑각 x10 + 검은 핵 x3 | 에이트르 회복 |
| 파데르 | 잿불의 땅 | 그을린 뼈 x10 + 모르겐 힘줄 x5 | 화염 저항 |

각 보스는 2페이즈, 고유 특수기(번개 세례·돌진·뿌리 강타·독 구름·서리 브레스·유성우·화염 광선·하수인 소환)를 씁니다.

### 제작 · 건축
- **190여 종 아이템** — 재료/음식/무기/방패/방어구/도구/화살/트로피.
- 작업대 · 대장간 · 가마솥 · 장인의 탁자 · 석공대 (부속으로 레벨 업그레이드).
- 제련소 · 숯가마 · 용광로 · 요리 화로(방치하면 탐) · 풍차 · 물레 · 발효조.
- 장비 **★1~★4 강화**.
- **60여 종 건축 조각** + **구조 무결성 전파** — 지면에서 멀어질수록 지지력이 떨어지고, 0이 되면 무너집니다.
- 격자 스냅 배치, 미리보기 고스트(가능/불가 색상), 철거 시 재료 절반 회수.
- 상자 · 침대 · 문 · 차원문(금속은 통과 불가) · 농사(작물 성장 단계).

### 지형 변형
- 괭이로 **평탄화 / 융기 / 굴착** (R 키로 모드 전환), 곡괭이로 땅파기.
- 1m 격자 높이 보정 맵을 이중선형 보간해 부드럽게 이어붙이고, 영향받은 청크의
  메시와 하이트맵 충돌을 즉시 다시 만듭니다. 원본 대비 ±12m 로 제한.

### 항해
- **뗏목 · 카르베 · 롱십** — 물 위에만 건조 가능. 4단 속도 + 방향타.
- 돛은 바람 방향과 세기에 반응하고(순풍/역풍), 좌초하면 속도를 잃습니다.
- 롱십/카르베는 화물칸이 있고, 부수면 재료 일부를 돌려받습니다.

### 낚시
- 낚싯대 + 미끼로 **던지기(차징) → 대기 → 입질 → 후킹 → 릴링** 전 과정.
- 릴링은 기력을 소모하며, 바닥나면 줄이 끊깁니다. 바이옴별 어종.

### 길들이기 · 번식
- 멧돼지(과일) · 늑대(고기) · 록스(곡물)에게 먹이를 떨어뜨려 길들입니다.
- 길들여진 동물은 주인을 따라다니며 적을 공격하고, 짝이 있으면 **새끼를 낳고**
  새끼는 시간이 지나 성체가 됩니다. 개체수 상한으로 폭주를 막습니다.

### 마법 (에이트르)
- 에이트르 음식(에이트르 빵 · 수액 스튜 · 버섯 오믈렛)을 먹어야 에이트르가 생깁니다.
- 지팡이 4종: **화염 · 서리 · 보호막 · 해골 소환**. 장인의 탁자에서 제작.
- 보호막은 받는 피해를 65% 줄이고, 소환된 해골은 아군으로 싸웁니다.

### 던전
- **고대 매장지(검은 숲) · 수몰된 묘지(늪) · 얼음 동굴(설산)** 총 23곳.
- 랜덤 워크로 방과 갈림길을 뚫고, 횃불·몬스터·보물상자를 배치합니다.
  가장 깊은 방에는 우두머리와 큰 보물이 있습니다.
- **특수 방 템플릿 21종** — 보물방·제단방·감옥방·함정방·산란방·서고(룬석)·버섯방·
  침수방·납골당·대장간·병영·우물방·열주실·붕괴실·연회실·사당·거미줄방·유해방·
  저장고·관측실.
- 지상과 분리된 지하 공간에 생성돼 지형과 충돌하지 않으며, 내부에서는
  날씨·바이옴·스폰이 멈추고 조명이 횃불로만 유지됩니다.

### 멀티플레이
- **ENet 기반 협동 플레이** (최대 9인). 타이틀 화면에서 `호스트 열기` 또는
  IP 를 넣고 `접속`. 기본 포트 27015.
- **호스트 권위 모델** — 월드는 시드로 결정되므로 지형 데이터를 전송하지 않고
  시드·시간·지형 변형분만 보냅니다. 몬스터는 호스트가 시뮬레이션하고 좌표만 뿌립니다.
- 동기화 대상: 플레이어 위치/자세, 몬스터 생성·이동·사망, 건축물 설치·철거,
  지형 변형, 시간대, 채팅(`Enter`).
- 늦게 들어온 접속자에게는 이미 존재하는 건축물·몬스터를 재현시킵니다.
- 오프라인일 때는 네트워크 경로 전체가 no-op 이라 싱글플레이 동작이 그대로입니다.

### 그 외
- **완전 한국어 지원** (기본값). 일시정지 메뉴에서 영어 전환. 한글 폰트 내장.
- 탐색한 지역만 드러나는 지도, 미니 통계, 숙련도 창.
- 저장/불러오기 (월드는 시드로 재생성, 지형 변형·건축물·무덤 등 변경분만 JSON 기록).

## 실행

Godot 4.4 이상이 필요합니다.

```bash
git clone https://github.com/<계정>/valhalla-viking-survival.git
cd valhalla-viking-survival
godot4 .              # 에디터에서 열기
# 또는
godot4 --path .       # 바로 실행
```

개발용 커맨드라인 훅:

```bash
godot4 --path . -- --auto --seed=12345          # 타이틀 건너뛰고 바로 시작
godot4 --path . -- --diag --seed=12345          # 월드 생성기 통계 출력
godot4 --path . -- --shots=/tmp/shots           # 자동 스크린샷 촬영
```

```
├─ player/     플레이어 컨트롤러 · 인벤토리 · 스탯 · 절차적 애니메이션
├─ entities/   자원 노드 · 아이템 드롭 · 투사체 · 몬스터 도감/AI · 보스 · 제단 · 상자/무덤
├─ building/   건축 조각 · 건축 시스템(스냅 · 구조 무결성)
├─ ui/         테마 · HUD · 인벤토리 · 제작 · 건축 · 지도 · 총괄
└─ dev/        자동 스크린샷 촬영기
```

핵심 설계 결정은 각 파일 상단 주석에 한국어로 적혀 있습니다.

## 알려진 한계

원작 Valheim 은 스튜디오가 수년간 만든 게임이고, 이 프로젝트는 그 **규모가 아니라 구조**를 재현한 것입니다.

- 멀티플레이는 ENet 직접 접속입니다 (기본 포트 27015, 최대 9인).
  **UPnP 자동 포트 포워딩**과 **전용 서버 모드**(`godot --headless -- --server`)를
  지원하므로 공유기 환경에서 외부 접속이 가능합니다. 다만 Steam 로비·매치메이킹·
  UPnP 미지원 공유기용 NAT 홀펀칭은 없습니다.

- 콘텐츠 **분량**은 원작보다 작습니다: 원작의 수백 종 아이템·수십 개 던전 방 템플릿·
  이벤트 대사·음악 트랙에 해당하는 양을 채우지 못했습니다.
- 그래픽은 Valheim 의 *스타일*(로우폴리 + 저해상도 텍스처 + 짙은 안개 + 강한 블룸)을
  목표로 재현한 것이며, 원작의 셰이더·에셋을 복제한 픽셀 단위 재현이 아닙니다.
  (원작 에셋을 쓰지 않는다는 전제 자체가 픽셀 단위 동일을 불가능하게 합니다.)
  원작의 정체는 **"Lo-Fi HD"** — 저해상도 픽셀 텍스처 + 현대적 조명/후처리입니다.
  이 프로젝트도 같은 방식을 씁니다: 48~64px 타일링 텍스처 14종(잔디·흙·바위·눈·모래·
  나무껍질·판자·석조·직물·털·금속·초가·잿불·잎)을 코드로 그려 nearest 필터로 붙이고,
  지형은 경사/고도로 4장을 스플랫하며, 나뭇잎은 알파가 뚫린 카드 뭉치입니다.
  ACES 톤매핑 · 대기 원근 · 선샤프트(볼류메트릭) · 젖음/웅덩이 · 불빛 떨림 ·
  타격 자국 · 바이옴별 부유 입자까지 구현돼 있고, 스크린스페이스 반사(SSR)와
  스크린스페이스 반사(SSR)는 켜져 있고, 볼류메트릭 구름은 레이마칭으로
  시도했으나 지평선 쪽 에일리어싱(세로 줄무늬)을 잡지 못해 3겹 텍스처 방식을
  유지했습니다. 캐릭터는 Skeleton3D 스키닝이 아니라 리그 노드를 코드로 회전시키는
  절차적 애니메이션입니다.
- 바다 괴수(서펜트), 두꺼비·거머리 같은 일부 잡몹, 무역상 NPC 는 미구현.
